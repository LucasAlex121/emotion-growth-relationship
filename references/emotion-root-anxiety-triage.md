# 情绪溯源与焦虑分流

## R — 原文（Reading）

> “顺着这个情绪和性格顺藤摸瓜，找到你内心的恐惧根源。”“焦虑也分两种，有效焦虑和无效焦虑。”
>
> — 陶白白，BV1qJjU6rEzg 00:07:12；BV1MpLp6DEQ9 00:09:03

---

## I — 方法论骨架（Interpretation）

表层情绪是信号，不是最终问题。先追问自己究竟害怕失去什么、最坏结果是什么、真正需要什么；再判断这份焦虑能否生成准备、决策或退出方案。能生成动作的保留，只有重复求证和想象的部分停止继续加工。

V2.0 增加“欲望—恐惧—行为—反馈”链：不仅问怕什么，也问想得到什么、恐惧驱动了什么行为、该行为实际造成了什么结果。若目标是把已经识别的根源说给对方，不在本模块继续分析，转 `translate-emotion-into-request`。

---

## A1 — 资料中的应用（Past Application）

### 关系抽离时的有效与无效焦虑

- **问题**: 发现对方开始抽离后，用户本能地道歉、讨好并要求对方不能离开。
- **方法论的使用**: 讲者把这种反应归为无效焦虑，并把“即使离开我也能生活”对应的准备归为有效焦虑。
- **结论**: 有效性取决于是否增加承受结果的能力。
- **结果**: 该区分成为后续分手状态重置的前置判断。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 Skill？

- 情绪很强但说不清真正害怕的结果
- 反复求证和想象却没有行动
- 焦虑里既有真实风险也有大量内耗

### 语言信号

- “我就是很焦虑，但不知道到底怕什么”
- “我不停问他会不会离开”
- “我想了很多，却一点准备都没做”

### 与相邻 Skill 的区分

- 与 `face-solve-transcend` 的区别：本 Skill 找根源并分流；后者处理已明确的问题。
- 与 `breakup-state-reset` 的区别：后者专门处理分手前后的决策和复联。
- 与 `diagnose-desire-fear-fixation` 的区别：本 Skill 分流焦虑；后者判断欲望阶段、被迫失去和执念。
- 与 `translate-emotion-into-request` 的区别：本 Skill 完成内部溯源；后者负责对外表达和修复。

## E — 可执行步骤（Execution）

1. **命名表层反应**
   - 动作: 记录触发事件、身体感受、冲动行为。
   - 完成标准: 能把事实与解释分开。
2. **追到恐惧根源**
   - 动作: 连续追问三次“如果发生，会失去什么”。
   - 完成标准: 得到一个具体可描述的最坏结果。
3. **分流焦虑**
   - 动作: 判断每个担忧是否能转成准备、决策或退出。
   - 完成标准: 每项被标记为有效或无效。
4. **行动或停止喂养**
   - 动作: 有效项进入任务清单；无效项停止重复求证并设反刍截止。
   - 完成标准: 至少完成一个准备动作。

## B — 边界（Boundary）

### 不要在以下情况使用

- 出现自伤、他伤、严重失眠或无法维持基本生活时，优先寻求专业支持。
- 已经明确具体问题和解决路径时，直接使用直面—解决—超越。

### 语料中明确出现的失败模式

- 以分析为名继续反刍。
- 把所有焦虑都当作必须执行的预警。

### 来源局限

- 有效/无效焦虑是语料中的功能性划分，不是临床诊断。

## 最新内部课增量（V2.1）

- 可把焦虑线索扩成“欲望—恐惧—行为—反馈”：想得到什么、怕失去什么、因此做了什么、结果又怎样强化解释（P00754—P00760、P00795—P00798）。
- 若用户已经指向一句短回复、表情或沉默，只是反复推演且不敢询问，转用 `turn-sensitivity-into-expression-and-verification`；本模块继续负责触发点和恐惧都不清楚的弥散焦虑。
- “恐惧与欲望同源”保持为作者内部解释，不写成外部验证事实。
