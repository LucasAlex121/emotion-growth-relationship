# 直面—解决—超越能力循环

## R — 原文（Reading）

> “放下痛苦的本质就是直面痛苦、超越痛苦。”“解决问题不在于问题本身，是赋予你解决问题的能力。”
>
> — 陶白白，BV1qJjU6rEzg 00:33:08；BV1M3DXBWEon 00:33:43

---

## I — 方法论骨架（Interpretation）

解决问题有两层结果：事件本身得到处理，以及你留下了以后还能使用的识别、判断和行动能力。逃避或即时止痛只改变感受，不改变问题结构。流程应从承认事实开始，拆出最小可控动作，完成闭环，再复盘形成能力证据。

V2.0 补充“痛苦—呼救—行动—自信”路径：痛苦本身不会自动带来成长，只有它触发了可完成的行动，并留下“我处理过”的证据，才会转成自信。若问题不是一次闭环，而是长期动力不足，转 `build-agency-through-feedback`。

## A1 — 资料中的应用（Past Application）

### 离婚与创业亏损的能力转化

- **问题**: 讲者先后经历离婚和持续亏损，试图控制关系与金钱结果。
- **方法论的使用**: 把两段经历分别解释为放下关系占有和金钱控制的训练，重新聚焦能做的内容与状态。
- **结论**: 痛苦只有经过处理和复盘才转化为能力。
- **结果**: 财务问题未完全解决，但讲者称判断和状态发生变化。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 Skill？

- 明知问题存在却长期拖延
- 反复用和好、娱乐或替代关系止痛
- 想从一次失败中留下可迁移方法

### 语言信号

- “我知道要处理，但一直不敢面对”
- “先让我不难受，其他以后再说”
- “这件事解决了，下次我还是不会”

### 与相邻 Skill 的区分

- 与 `emotion-root-anxiety-triage` 的区别：这里的问题已经明确。
- 与 `growth-joy-process` 的区别：这里解决具体问题；后者筛选长期投入路径。
- 与 `build-agency-through-feedback` 的区别：本 Skill 处理明确问题；后者为长期目标建立连续反馈。

## E — 可执行步骤（Execution）

1. **承认事实**
   - 动作: 写出不含评价的事实、损失和当前责任。
   - 完成标准: 事实可被第三方核对。
2. **拆最小闭环**
   - 动作: 选一个一周内能完成的处理动作。
   - 完成标准: 动作有负责人、截止时间和结果。
3. **完成并记录**
   - 动作: 执行动作并记录遇到的阻碍与调整。
   - 完成标准: 产生可观察结果，不以想明白代替完成。
4. **沉淀能力**
   - 动作: 总结下次遇到同类问题的触发信号和首个动作。
   - 完成标准: 形成一条可复用规则。

## B — 边界（Boundary）

### 不要在以下情况使用

- 问题根源尚不清楚时先做情绪溯源。
- 涉及专业法律、医疗或财务判断时，应结合专业意见。

### 语料中明确出现的失败模式

- 只强调接受却不行动。
- 只处理事件，不记录下一次如何更快识别与应对。

### 来源局限

- 个人成长框架不能替代专业风险评估。
