# 分手前后状态重置

## R — 原文（Reading）

> “提分手的时候先想，如果对方真的分手了，你能不能接受。”“你现在这种状态最好不要去找他。”“想和好，就把这事儿全部消化掉。”
>
> — 陶白白，BV1KsN36WEKy 00:12:32；BV15D5x6NEuy 00:06:13；BV1MuoyB5EFG 00:07:15

---

## I — 方法论骨架（Interpretation）

分手与复联都不应只是即时止痛动作。提分手前要确认自己能承担对方接受；分手后先恢复吃睡、工作和生活支点，复盘导致冲突的重复模式，决定哪些旧事必须处理、哪些选择复合后不再追责。只有状态变化可被看见，才进入低压力接触。

V2.0 增加三项前置分流：当前真正目标是修复关系、消除不甘，还是恢复生活；痛苦主要来自关系价值还是强行抽离；所谓复合是恢复原状，还是双方重新评估并建立新互动。若尚未判断分手主因，先用 `diagnose-breakup-past-present-future`；若核心是执念和失控，辅助 `diagnose-desire-fear-fixation`。

## A1 — 资料中的应用（Past Application）

### 工作焦虑稳定后再经多人局接触

- **问题**: 连麦者因工作焦虑和情绪对抗分手，只剩弱联系。
- **方法论的使用**: 讲者建议先调整工作与状态，再通过共同朋友的多人局让对方看到变化，而不是一对一强谈复合。
- **结论**: 复联前先改变可见状态和场景压力。
- **结果**: 连麦者接受方案；最终复合结果未说明。

## A2 — 触发场景（Future Trigger）

### 用户会在什么情境下需要这个 Skill？

- 情绪不稳时想用分手威胁
- 分手后吃不下睡不着却想马上联系
- 旧事未消化就准备复合
- 需要判断何时适合低压力复联

### 语言信号

- “我现在很崩溃，先联系他再说”
- “我提分手只是想让他哄我”
- “我们要和好，但旧账我还放不下”

### 与相邻 Skill 的区分

- 与 `high-position-light-contact` 的区别：本 Skill 判断并建立复联资格；后者处理资格满足后的首次消息。
- 与 `emotion-root-anxiety-triage` 的区别：本 Skill 专门组织分手前后流程。
- 与 `diagnose-breakup-past-present-future` 的区别：本 Skill 建立行动资格；后者判断过去、现在、未来哪条原因线权重最高。

## E — 可执行步骤（Execution）

1. **承担真实结果**
   - 动作: 提分手或复联前分别写出最坏结果，确认能否承担。
   - 完成标准: 不再把分手当情绪威胁。
2. **恢复基本状态**
   - 动作: 先恢复吃睡、工作、支持和日程。
   - 完成标准: 至少一周能维持基本生活。
   - 判停条件: 仍无法维持时继续稳定，不复联。
3. **复盘重复模式**
   - 动作: 列出触发、反应、后果和需要改变的行为。
   - 完成标准: 至少有一个可见改变。
4. **明确真实目标**
   - 动作: 在修复关系、处理不甘和恢复生活中选择当前主目标。
   - 完成标准: 下一步动作与主目标一致，不再用复联解决所有痛苦。
5. **处理旧事**
   - 动作: 决定哪些必须解决、哪些复合后不再反复追责。
   - 完成标准: 没有模糊旧账包袱。
6. **选择低压接触**
   - 动作: 若仍决定复联，优先自然或多人场景。
   - 完成标准: 接触目的不是当场逼出复合。

## B — 边界（Boundary）

### 不要在以下情况使用

- 对方明确拒绝联系时停止复联。
- 存在暴力、威胁或持续骚扰时优先安全与专业支持。

### 语料中明确出现的失败模式

- 自身焦虑未稳就启动挽回。
- 旧事未消化，见面后重新质问。
- 一对一场景让对方提前进入高度戒备。
- 只研究复联，不修正重复模式。

### 来源局限

- 状态重置不能保证关系恢复，只提高判断和接触质量。

## 最新内部课增量（V2.1）

- 增加“情绪强度与关系价值分离”：强烈反扑可能包含突然抽离、不适应、不甘或生活支点丢失，不自动证明关系值得恢复（P01231—P01240）。
- 状态恢复补充吃饭、睡眠、过去兴趣、个人计划与关系外任务（P01327—P01358）。
- 状态稳定后，若任务是分清责任与提取规律，转用 `review-relationship-fracture-in-two-columns`；若准备复联，进入 `reconnection-stage-gates` 判断阶段。
