# 情感成长与亲密关系 V2.1：共享术语词典

> 本词典解释这些词在本资料集中的内部用法，不把讲者的经验命题当作通行学术定义。涉及控制、性别、星座和确定性判断时，必须同时读取 `SOURCE_CLAIMS.md` 的边界。

| 术语 | V2.1 中的可操作含义 | 关键区别与边界 |
|---|---|---|
| 主体性 | 识别自己的需要和可控行动，主动选择、承担反馈，并保留最后决定权 | 不等于只按脾气做事；重点是控制自己的选择，不是控制别人 |
| 支点 | 分担生活意义和情绪压力的人、事、目标与能力来源 | 不是短期转移注意力，而是能持续运转的生活结构 |
| 受害者心态 | 讲者所批评的：把需要和选择外包，结果不符时只剩归咎和自我折磨 | 不能用来否认真实伤害、侵害责任或安全风险 |
| 欲望与恐惧 | “想得到什么”与“怕失去什么”的一对行为动力 | “二者同源”是讲者经验命题，诊断时只能作为待本人确认的假设 |
| 欲望阶段 | 区分尚未体验、正在体验、主动不再需要，以及被迫中止 | 主动放下与失败后的自我安慰不同；危险关系不要求先“得到”再退出 |
| 觉醒／主动放下 | 经过体验和理解后，仍有选择能力，却决定不再被某个欲望支配 | 不等于压抑、不痛、认输或被动失去 |
| 执念 | 对不可由自身行动直接抵达的对象或唯一结果持续紧抓 | 与可拆解、可试验、允许改路的愿望不同 |
| 破情关 | 经历关系与失去后，仍保留爱、信任、选择和退出的能力 | 不等于追回前任、战胜对方或变得无情 |
| 反馈 | 某次行动结果提供的信息，用于继续、调整或停止 | “没有做好”不等于“我不好”；反馈不是身份判决 |
| 盼头 | 小结果和可见进展形成的下一步动力 | 不只是空泛希望，必须有短反馈周期和可观察证据 |
| 委屈 | 不情愿或暗含回报要求的投入形成的被亏欠感 | 既要查隐性合同，也要承认客观失约和不公平 |
| 隐性合同 | 自己未说出口，却默认对方应以特定方式回报的交换预期 | 真诚不自动生成等量回报义务；现实协议仍需明确 |
| 有效焦虑 | 能导向准备、自立、决策或能力提升的焦虑 | 以是否增加行动能力判断，不以情绪强度判断 |
| 无效焦虑 | 反复求确定、讨好、道歉，却没有提升承受力与解决力 | 不等于焦虑本身无意义；仍应先识别风险和需要 |
| 情绪—事实—请求 | 先识别情绪根源，再描述可核对事实，提出可回应请求 | 处理情绪不等于免除行为责任；请求也不保证对方答应 |
| 识人断人 | 从跨场景行为提出暂定画像，小成本验证，并反照自己的偏见与适配度 | 不是凭几句话判好坏、读心或贴人格标签 |
| 价值／价值感 | 某段关系和场景里能被感知的供给、承担与匹配 | 不等于人的尊严或固定身价；不能把匹配度写成人的总分 |
| 恋爱体验 | 日常舒适、冲突、被理解、现实协作、投入回报与修复记忆的总体感受 | 不只是浪漫、哄开心或单一“情绪价值” |
| 爱情生活 | 两个人实际如何相处、分工、规划、承担现实并决定是否继续的生活系统 | 与抽象的“爱”不同；感情强度不能覆盖结构性不合 |
| 感受爱／感受到被爱 | 前者是自己产生在意与投入，后者是接收对方的关心、回应与照顾 | 两条通道都需检查，不是固定的爱人／被爱角色 |
| 过去—现在—未来 | 过去看旧伤与信任；现在看当下体验；未来看现实条件与共同规划 | 是可同时存在的加权原因线，不是互斥的时间顺序 |
| 主动权／高低位 | 管理自己的投入、节奏、选择与退出，不被单一关系结果牵着走 | 不等于慢回消息、压住对方或故意制造焦虑 |
| 真诚 | 动机真实、经过思考、可被对方理解，同时保留收回权 | 真诚不是讨债合同，也不保证被选择 |
| 控制人／控制欲望 | 讲者区分直接命令与通过供给、撤回、奖惩影响动机 | 秘密利用恐惧仍可能是操控；V2.0 只保留透明边界和双方可退出性 |
| 奖励／惩罚 | 对希望继续的行为给出回应，对越界行为撤回相应投入并让其承担自然后果 | 不得把伴侣当训练对象；羞辱、报复、恐吓和故意诱发焦虑不属于健康边界 |
| 得到／失去感 | “得到”多指确信已掌握对方的心；“失去感”是供给可能消失的损失预期 | 因果效果未经证明；自然后果与故意制造不确定性必须分开 |
| 情绪反扑 | 分手后因日常依赖、控制感、未来投射突然中断而出现的延迟性强情绪 | 不自动等于仍深爱或必须复合，也要排查真实哀伤、创伤和安全问题 |
| 强行抽离 | 尚未准备好时，被突然从依赖、习惯和共同未来中切断 | 暴力、骚扰等情境仍应安全优先，不能借此劝留 |
| 重新吸引 | 关系破裂后以真实改变和重新选择建立新互动结构 | 不等于诱发焦虑、窥探或恢复原样；拒绝和边界必须被尊重 |
| 真性／假性分手 | 讲者用“冷静通知／高情绪控诉”区分离开倾向的经验线索 | 不是可靠真假判定；任何明确分手都必须按真实边界对待 |
| 外部规则／社会脚本 | 来自家庭、学校、组织或关系的“应该／必须”，需要检查是否仍由本人认可 | 不等于所有外部规则都应打破；现实责任、安全约束和资源条件要单独保留 |
| 大脑／欲望／感受 | 作者所称的三种内部状态：现实计划、刺激与得到、持续体验 | 是内部解释模型，不是三类人格，也不是医学或神经科学分类 |
| 上帝视角 | 暂时离开即时情绪，从第三方位置回看双方事实、欲望、恐惧和结果 | 不表示掌握绝对真相；未知动机仍应保持未知 |
| 客体分离 | 原文用语：把对方的选择与自己的可调整部分分开复盘 | 不作临床术语使用，也不要求责任平均分配 |
| 高敏感人格 | 作者用来概括在意评价、捕捉细节、怕麻烦别人、反复推演等特征 | 文档没有量表或诊断标准；运行时以行为组合而非人格标签触发 |
| 弱联系 | 分手后有限、自然、有现实理由的接触，用于观察窗口与回应 | 原文也出现“若联系”等 ASR 变体；不是完全断联，也不是持续报备或纠缠 |
| 复联阶段门 | 从状态资格、有限联系、稳定回应、见面、旧问题处理到关系确认的晋级证据 | 阶段只说明互动位置；单次回复、见面或亲密不等于复合 |
| 延时批判法 | 作者命名的局部技法：不在情绪高峰立即批判，延后到可承接时表达影响 | 完整结构集中在一个课程语境；只作为表达时机案例，不写成必然有效规律 |
| 借势 | 最新课程最后一组技法的系列总称，包含低成本试探、失去感、愧疚与反馈 | 不是单一运行模块；必须按具体任务路由，不能用总称绕过边界 |
| 爱上跟对方相处时的自己 | 用相处中的自我状态和实际生活体验判断关系，而不只看抽象承诺 | 是作者总结性主张；仍需同时观察对方状态、现实匹配和持续行为 |

## 使用原则

1. 先按讲者原意理解，再把它转成可观察、可验证、可退出的行动语言。
2. 术语只能生成假设，不能替用户或第三方下确定结论。
3. 涉及暴力、胁迫、骚扰、自伤、财务控制或隐私侵犯时，安全和专业支持优先于关系技巧。
4. 星座、性别和人格分型只能作为讲者的叙事材料，不能作为诊断证据。
