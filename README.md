# 情感成长与亲密关系 Skill V2.1

这是一个面向 Codex 的个人成长与亲密关系分析 Skill，基于网上某些个人情感相关课程与视频转写资料整理而成。它将主体性、情绪表达、识人择偶、恋爱体验、关系破裂复盘、分手状态重建和复联阶段判断等内容整理为 29 个可路由模块，回答时会先识别用户当前的真实目标与关系阶段，再选择一个主模块，避免把所有理论一次性套用到具体关系中。

## 主要特点

- 29 个独立模块，覆盖个人成长、关系经营、分手复盘与复联判断。
- 区分课程作者主张、可观察事实、本次解释和仍待验证项。
- 对星座分型、真假性分手、愧疚、奖惩和冷热策略等内容保留证据边界，不把预测写成必然结果。
- 保留原始资料的作者署名与来源定位；转写不清处不擅自修正。

## 安装

将整个仓库复制到 Codex 的技能目录：

```text
~/.codex/skills/emotion-growth-relationship
```

安装后可这样调用：

```text
使用 $emotion-growth-relationship 分析我的情况，先按 V2.1 索引选择主模块，再给出下一步。
```

## 使用边界

本 Skill 用于关系梳理、行动设计和课程观点检索，不替代医疗、心理治疗、法律意见或危机干预。遇到明确拒绝、暴力、威胁、骚扰或身心危机时，应优先处理安全与专业求助，而不是继续使用关系策略。

## 目录

- `SKILL.md`：技能入口与总路由规则。
- `references/INDEX.md`：29 个模块的路由索引。
- `references/`：模块正文、术语表、来源地图与证据边界。
- `tests/`：新增模块的路由测试与验证记录。
